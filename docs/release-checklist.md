# 发布检查表

本检查表用于区分“算法可复现”“工程可构建”和“可接入飞控”。所有未有直接证据的项目保持未完成。

## A. 核心算法

- [x] EGO 语义的三维概率体素、raycast、膨胀和未知空间策略。
- [x] 三维 26 邻域 A*、严格对角检查、预算和失败状态。
- [x] 三次 B-spline、物理导数、五次航点参考、严格七阶 minimum-snap、确定性时间分配、弧长重采样。
- [x] 静态平滑/避障/动力学优化和发布前静态门控。
- [x] KF-CV/CA 预测、协方差传播和动态 3-sigma 硬门控。
- [x] 统一延迟、定位/执行协方差、存在概率和地图质量风险。
- [x] 动态软风险优化、异常/超预算回退和回退后硬门控。
- [x] 重规划 FSM、轨迹接续、信息过期、显式 reset 和急停。

## 当前结论

截至 2026-09-02，本机 Jazzy 的 A/B 项目（包括飞控接纳边界、静态和软风险性能记录）已有证据；许可证元数据和顶层文件已完成。Humble 实跑、C，以及 D 中的实际安装 SBOM、正式版本和干净双发行版 smoke test 仍未完成。没有 PX4/GZ 或真实飞行证据时，不应把工作区称为真实飞行验收版本。
