# ADR 0012：统一风险策略 v1 和自主实施边界

- 日期：2026-09-02
- 状态：Accepted
- 范围：`aurora_risk`、`aurora_planner_core`、`aurora_ros` 以及后续轨迹优化/验证模块

## 背景

AURORA 已有动态目标 KF-CV/CA 预测和 3-sigma 保守包络门控，但定位、执行误差、延迟、存在概率和静态地图质量尚未进入同一风险语义。继续实现这些能力前，需要冻结不会被局部代码各自解释的全局规则。

## 决策

### 1. 时间语义

对轨迹样本绝对时刻 `t`，风险评估使用目标预测查询时刻：

```text
t_effective = t + sensing_delay + tracking_delay + planning_delay
              + execution_delay + safety_margin
```

轨迹本身的绝对执行时间不被静默平移。预测查询不得超出有效预测窗口；延迟字段必须有限且非负。

### 2. 协方差语义

在同一 `map` 坐标系和同一有效时刻下，独立位置误差直接相加：

```text
Sigma_relative = Sigma_obstacle
               + Sigma_localization
               + Sigma_execution
               + Sigma_trajectory_sample
```

未提供的协方差保持“缺失”状态，由风险报告标记；不得静默宣称零误差。协方差必须有限、对称、半正定，数值容差内的修正必须计入诊断。

### 3. 存在概率

目标不因低存在概率而从硬安全检查中删除。硬 3-sigma 包络始终检查。软风险使用：

```text
p_eff = max(existence_probability, 0.05)
weighted_risk = p_eff * geometric_risk
```

单个样本的 `geometric_risk` 使用归一化安全间距计算；风险报告的动态风险采用最坏目标/最坏时刻聚合，以保持可解释性和对目标数量的稳定语义。优化器的时间积分可使用相同分项风险，但不能覆盖硬门控。

### 4. 地图质量

- `OCCUPIED`、`OUT_OF_MAP` 直接拒绝。
- `UNKNOWN` 默认拒绝；只有显式安全配置才允许进入软风险流程。
- `FREE` 的软风险由占据概率、观测年龄和置信度构成。首版采用有界单调映射：占据概率和观测年龄越高，风险越高；置信度越低，风险越高。
- 地图质量缺失不等于自由空间，进入信息风险降级并在报告中标记来源。

地图风险的具体参数以配置文件冻结，并用单调性测试和场景回放校准；不能由单个调用点临时定义。

### 5. 优化和安全边界

动态/地图风险首先作为 B-spline 优化的软目标，静态/动态 3-sigma、占据/未知、动力学和时间有效性仍作为发布前硬门控。软优化失败、超时或输入不完整时回退 EGO 静态基线，并重新执行完整硬门控。

## 不采用的方案

- 不把动态障碍物永久写入静态占据层，避免丢失时间维度。
- 不以低存在概率直接忽略目标。
- 不把当前保守 3-sigma 几何分数描述为精确碰撞概率证明。
- 不在没有轨迹/目标数据集和回退模型时引入学习预测器。

## 后果

风险值是可比较、可追溯的工程指标，但 `p_eff=0.05`、风险权重和地图质量参数仍需要基于数据集标定。任何改变上述硬安全、时间或概率语义的后续实现必须新增 ADR，并同步消息、测试和回放基线。
